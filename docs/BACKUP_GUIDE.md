# Trip2Talk Business Records Backup Guide

## Monthly Tasks (ทำทุกสิ้นเดือน)

1. Export Monthly Report CSV from Companion app → save to `Google Drive/Trip2Talk/Finance/[Year]/`
2. Export Guest Consents CSV from Consent tab → save to `Google Drive/Trip2Talk/Legal/Consents/[Year]/`
3. Export Expense receipts from Supabase Storage → `Google Drive/Trip2Talk/Finance/Receipts/`

## Yearly Tasks (ทำทุกสิ้นปี)

1. Generate Business Passport → save to `Google Drive/Trip2Talk/Business/`
2. Export full customer database CSV
3. Export all reviews
4. Screenshot all social media metrics (Instagram, Facebook)
5. Record all subscription costs (Vercel, Supabase, Cursor, Hostinger)
